# Roadmap

The roadmap lives in three documents, at three levels of resolution:

| Document | What it is |
|---|---|
| [RFC-0099: Roadmap](rfcs/0099-roadmap.md) | The phases, the gates G0–G5, and *why* the order is what it is |
| [MVP Roadmap](mvp-roadmap.md) | The ordered work breakdown for the MVP — Phases 0–4, milestones with done-when conditions |
| [`PIPELINE.md`](../PIPELINE.md) | Live progress. What is done, what is next, what the next session needs to know |

**The MVP is: a person opens a real Git repository on a mid-range Android phone, in airplane
mode, asks a question about the code, gets a useful answer, makes an edit, reviews the diff, and
commits.** Everything is ordered around proving that before building on top of it.

---

*This file previously carried a fourth, older phase list that contradicted RFC-0099 — it put a
shell sandbox and MCP inside the Android MVP, both of which the platform capability profiles
(RFC-0049) and D17 rule out on that profile. Two roadmaps that disagree are worse than one that
is merely incomplete, so it was replaced with this index rather than updated in parallel.*
