# Roadmap

## Phase 0: Architecture

- Define runtime architecture and core subsystems
- Establish RFC process and RFC-based design documents
- Design offline-first storage and sync strategy
- Specify security model and capability-based access control
- Design event bus and reactive layers

## Phase 1: Android MVP

- Android UI frontend
- Local SQLite storage and sync engine
- Git integration (clone, commit, push)
- Shell execution sandbox
- Basic AI agent loop
- MCP server integration

## Phase 2: Desktop

- Desktop UI (macOS, Linux, Windows)
- Unified storage backend (shared with Android)
- Enhanced editor and workspace UI
- Local model support
- Advanced project management

## Phase 3: Platform

- Collaborative workflows
- Remote execution (with encryption and permission model)
- Plugin SDK and ecosystem
- Knowledge engine and semantic indexing
- Advanced instruction orchestration
- Multi-user projects
